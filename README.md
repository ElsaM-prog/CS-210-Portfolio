# CS 210 Portfolio – Corner Grocer

## Project Summary

For this project, I developed a C++ program for a grocery store that tracks how often different items are purchased. The program reads information from an input file and allows users to search for specific items, view purchase frequencies, and display a histogram. It also creates a backup file containing the item frequencies. The purpose of the project was to help the grocery store better understand customer purchasing patterns.

## What Did I Do Particularly Well?

I think one thing I did well was organizing the program into separate files and functions rather than putting everything into one place. This made the code easier to understand and manage. I also liked that the program provides different ways to view the same information depending on what the user needs.

## Where Could I Improve My Code?

One area I could improve is error handling, especially when dealing with missing input files or unexpected user entries. I could also make the program more flexible when handling larger datasets or different file formats. These improvements would make the program more reliable and adaptable.

## What Was Most Challenging?

The most challenging part for me was getting all the files to work together correctly in CLion. At one point, the program kept displaying the original code even though I had updated the project files. Later, it couldn't locate the input file. I had to troubleshoot each problem individually and understand how the files were connected. This experience taught me that programming isn't just about writing code but also understanding the environment where the code runs. I used course resources, troubleshooting, and AI assistance to work through these challenges.

## What Skills Will Transfer to Future Projects?

Some of the most valuable skills I gained were working with multiple C++ files, using classes and functions, reading and writing files, and troubleshooting errors. I also became more comfortable understanding how different parts of a program work together. I think these skills will be useful in future courses and more complex programming projects.

## How Did I Make My Program Maintainable, Readable, and Adaptable?

I separated the program into a main file, a header file, and an implementation file. I also used descriptive function names and organized the program around specific tasks. This makes the code easier to follow and allows individual functions to be modified without rewriting the entire program.
